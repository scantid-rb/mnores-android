# ShipInventory Android

Cliente Android nativo de ShipInventory, desarrollado con Expo/React Native y diseñado para trabajar offline-first contra la API de ShipInventory.

## Versión

- Aplicación: **0.1.4**
- API requerida: **1.4.5**
- Servidor predeterminado: `https://mnores.atwebpages.com`
